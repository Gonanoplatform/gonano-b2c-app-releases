Find companies, add contacts, write roof-restoration outreach, and send it from your own Gmail, all on your computer.

## First launch

The app isn't from an app store yet, so your computer asks once whether you trust it.

**Mac**
1. Open the zip, then drag **GoNano Outreach** into **Applications**.
2. Double-click it. If macOS says it can't be opened, open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to GoNano Outreach.
3. The app opens in your browser. It has no Dock icon and keeps running in the background. Use **Quit app** in the sidebar to stop it.

**Windows**
1. Double-click **GoNano-Outreach.exe**. If "Windows protected your PC" appears, click **More info → Run anyway**.
2. The app opens in your browser. Keep the small black window open while you use the app; closing it quits the app.

Tip: move the file somewhere permanent first (for example, a "GoNano" folder in Documents) so updates have a stable place to go.

**Linux**: extract the archive and run `GoNano-Outreach/gonano-outreach`.

## Updates

The app checks for new versions every hour. When one is out, you'll see **"Version … is ready"** with what's new, plus an **Update now** button. If nobody's using the app, it updates itself. Your companies, contacts, drafts, history and settings are kept on your computer and are never touched by an update. If a new version ever fails to start, the previous one comes back automatically.
